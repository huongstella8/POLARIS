MODULE 1 – CONDITIONALS

0️⃣ Zero & Type 1 Conditionals

Real situations – general truths and likely future events

✦ Zero Conditional – General Truths / Facts

If/When + present simple, present simple

If you heat water to 100°C, it boils. (always true)
When people don't sleep enough, they feel tired. (general fact)

🔮 Type 1 – Real / Likely Future

  • Used for situations that are possible or likely in the future
  • If + present simple, will + base verb
  • Can also use: can, may, might, should, must instead of will
If-clause (condition)Main clause (result)
If it rains tomorrow,I will stay home.
If you study hard,you might pass the exam.
If she doesn't hurry,she will miss the bus.

📌 Key Rules

  • NEVER use will in the if-clause: ✗ If it will rain… → ✓ If it rains…
  • The if-clause can come first or second. Comma only when if-clause is first.
  • Zero conditional: can use when instead of if (same meaning)
💡 Phân biệt Zero vs Type 1:
Zero: If you heat water, it boils. → luôn đúng, bất biến (quy luật tự nhiên/thói quen)
Type 1: If it rains tomorrow, I will stay home. → có thể xảy ra trong tương lai cụ thể

MODULE 1 – CONDITIONALS

2️⃣ Type 2 Conditional

Unreal present/future – imagining things differently from reality

✦ Type 2 – Unreal Present / Future

If + past simple, would/could/might + base verb

If I were a bird, I would fly everywhere. (I'm not a bird — imaginary)
If she had more money, she could travel the world. (she doesn't have much money)

📐 Structure

If-clauseMain clause
If + subject + past simplesubject + would/could/might + base verb
If I lived in Hanoi,I would visit the museums every weekend.
If she spoke French,she could get the job.

📌 Special: "were" for all subjects

  • In formal/correct English: use were for ALL subjects (not was):
    ✓ If I were you, I would study harder.
    ✓ If she were here, she would help us.
  • In informal speech, was is acceptable for I/he/she/it
  • If I were you… = very common idiom for giving advice
💡 Type 1 vs Type 2:
Type 1: If it rains, I will stay home. → có thể xảy ra (mang ô phòng khi)
Type 2: If it rained every day, I would move away. → không thực tế ở hiện tại (giả định)

MODULE 1 – CONDITIONALS

3️⃣ Type 3 Conditional

Unreal past – imagining how things could have been different

✦ Type 3 – Unreal Past

If + past perfect, would/could/might + have + past participle

If I had studied harder, I would have passed the exam. (I didn't study → I failed)
If she hadn't missed the bus, she wouldn't have been late. (she missed it → she was late)

📐 Structure

If-clause (past perfect)Main clause
If + subject + had + p.p.subject + would/could/might + have + p.p.
If he had arrived on time,we would have started the meeting.
If they hadn't argued,they might have stayed together.

📌 Common Contractions

  • If I hadn't = If I had not
  • I would've passed = I would have passed (spoken English)
  • I wouldn't have = I would not have
  • Inversion (formal): Had I known, I would have helped. = If I had known…
💡 Diễn đạt hối tiếc và phê phán:
Type 3 thường diễn đạt sự hối tiếc hoặc phê bình về quá khứ:
If you had told me earlier, I could have helped you. (tiếc là bạn không nói)
If she hadn't been so careless, the accident wouldn't have happened. (phê bình)

MODULE 1 – CONDITIONALS

🔀 Mixed & Special Conditionals

Mixed types + unless / provided that / as long as / in case / even if

✦ Mixed Conditionals

Mix past unreal condition with present result, or present unreal condition with past result.

🔀 Two Common Mixed Types

TypeStructureExample
Past → Present
(unreal past condition, present result)		If + past perfect, would + base verbIf I had studied medicine, I would be a doctor now.
Present → Past
(unreal present condition, past result)		If + past simple, would have + p.p.If I were more organised, I wouldn't have forgotten the meeting.

🔑 Special Conditional Words

WordMeaningExample
unlessif not / except ifI'll go unless it rains. (= if it doesn't rain)
provided (that)on the condition thatYou can borrow it provided (that) you return it tomorrow.
as long ason the condition thatI'll help you as long as you try your best.
in casebecause it is possible thatTake an umbrella in case it rains. (= because it might rain)
even ifregardless of whetherI'll finish this even if it takes all night.
💡 unless vs if not:
unless = if not trong hầu hết các trường hợp — nhưng KHÔNG dùng unless với câu phủ định:
✓ Unless you hurry, you'll be late. = If you don't hurry, you'll be late.
✗ Unless you don't hurry, you'll be late. (sai — double negative)

MODULE 2 – REPORTED SPEECH

📢 Reported Statements

Tense backshift, pronoun & time expression changes

✦ Reporting a Statement

Direct: "I am tired." → Reported: She said (that) she was tired.

⏪ Tense Backshift (one step back)

Direct SpeechReported Speech
present simple → am/is/arepast simple → was/were
present continuous → is/are doingpast continuous → was/were doing
present perfect → has/have donepast perfect → had done
past simple → didpast perfect → had done
will → willwould → would
can → cancould → could
may → maymight → might

🔄 Other Changes

CategoryDirectReported
PronounsI → she/he; we → they; my → her/hisDepends on context
Timenow → then; today → that day; yesterday → the day before; tomorrow → the next day / the following day
Placehere → there; this → that; these → those
💡 Khi KHÔNG cần backshift:
Nếu câu nói vẫn còn đúng tại thời điểm tường thuật, có thể giữ nguyên thì:
"The Earth is round." → He said (that) the Earth is round. (sự thật hiển nhiên)
"I love you." → He says (that) he loves her. (reporting verb ở hiện tại → không backshift)

MODULE 2 – REPORTED SPEECH

❓ Reported Questions

Embedding yes/no and wh-questions with statement word order

✦ Reporting a Question

Direct: "Where do you live?" → Reported: She asked me where I lived.

📋 Two Types of Reported Questions

TypeConnectorDirect → Reported
Yes/No questionsif / whether"Are you ready?" → He asked if I was ready.
Wh- questionsthe same wh-word"What do you want?" → She asked what I wanted.

📌 Critical Rule: Statement Word Order

  • In reported questions, always use statement word order (S + V), NOT question order.
  • ✗ She asked where did I live.
  • ✓ She asked where I lived.
  • ✗ He asked if was I hungry.
  • ✓ He asked if I was hungry.
  • Do NOT use a question mark in reported questions.
💡 Động từ tường thuật cho câu hỏi:
ask = câu hỏi thông thường: She asked me where I was going.
wonder = tự hỏi: He wondered whether she would come.
want to know: They wanted to know how much it cost.
inquire (formal): He inquired whether a room was available.

MODULE 2 – REPORTED SPEECH

📋 Reported Commands & Requests

tell/ask/warn/advise + object + (not) to-infinitive

✦ Reporting Commands and Requests

Direct: "Open the window." → Reported: She told me to open the window.

📐 Structure

  • Positive: reporting verb + object + to + base verb
    He told her to sit down.
  • Negative: reporting verb + object + not to + base verb
    She told me not to be late.

🔑 Reporting Verbs for Commands/Requests

VerbDirectReported
tell (command)"Sit down!"He told me to sit down.
ask (polite request)"Please close the door."She asked me to close the door.
warn (danger)"Don't touch that!"He warned me not to touch it.
advise (advice)"You should rest."She advised me to rest.
remind (reminder)"Don't forget your keys."He reminded me not to forget my keys.
encourage (motivation)"Keep trying!"She encouraged me to keep trying.
forbid (prohibition)"Don't smoke here."He forbade me to smoke there.
💡 say vs tell:
say → no object: She said (that) she was tired.
tell → needs object: She told me (that) she was tired.
✗ She said me to come. → ✓ She told me to come.

MODULE 3 – PASSIVE VOICE

🔄 Present & Past Passive

Shifting focus from the doer to the action or the receiver

✦ Active → Passive

Active: The chef cooks the meal. → Passive: The meal is cooked by the chef.

📐 Passive Structures

TenseActivePassive (be + p.p.)
Present simpleThey make cars here.Cars are made here.
Present continuousThey are building a road.A road is being built.
Past simpleSomeone stole my bag.My bag was stolen.
Past continuousThey were repairing the bridge.The bridge was being repaired.

📌 When to Use Passive

  • The doer is unknown: My wallet was stolen.
  • The doer is obvious: He was arrested. (by the police — obvious)
  • The doer is unimportant: The bridge was built in 1990.
  • In formal/academic writing: The experiment was conducted three times.
  • To focus on the result: The report has been completed.
💡 By + agent: Chỉ dùng "by + tác nhân" khi tác nhân quan trọng hoặc đặc biệt:
✓ The Mona Lisa was painted by Leonardo da Vinci. (quan trọng)
✗ The email was sent by someone. (không cần thiết)
with dùng cho công cụ: The letter was written with a quill.

MODULE 3 – PASSIVE VOICE

⚡ Perfect & Modal Passive

has/have/had been done · must/should/can be done

⏰ Perfect Passive

TenseActivePassive
Present perfectThey have finished the project.The project has been finished.
Past perfectThey had sent the report.The report had been sent.
Future simpleThey will complete it.It will be completed.

🔧 Modal Passive

Structure: modal + be + past participle

ModalActivePassive
mustYou must submit the form.The form must be submitted.
shouldThey should repair the road.The road should be repaired.
canWe can solve this problem.This problem can be solved.
could haveThey could have prevented it.It could have been prevented.
should haveSomeone should have told her.She should have been told.
💡 Passive trong văn học thuật:
Modal passive rất phổ biến trong văn viết học thuật và báo cáo:
The results should be interpreted carefully.
Further research must be conducted to confirm these findings.
The error could have been avoided with better planning.

MODULE 3 – PASSIVE VOICE

📰 Passive with Reporting Verbs

It is said that… / He is believed to… / She is reported to have…

✦ Impersonal Passive (News / Formal)

Used to report information without identifying the source, very common in news and academic English.

📐 Two Structures

StructureExample
It + passive + that clauseIt is said that he is very wealthy.
Subject + passive + to-infinitiveHe is said to be very wealthy.
Subject + passive + to have + p.p.
(for past reference)		She is reported to have left the country.

🔑 Common Reporting Verbs

say · believe · report · think · consider · claim · know · expect · understand · allege · estimate

All three equivalent:
People say he is a genius.
→ It is said that he is a genius.
→ He is said to be a genius.
Past action:
People believe she left yesterday.
→ It is believed that she left yesterday.
→ She is believed to have left yesterday.
💡 Văn báo và học thuật:
Cấu trúc này cực kỳ phổ biến trong tin tức và học thuật để tránh nêu nguồn:
It is estimated that over 50 million people speak Vietnamese worldwide.
The company is thought to be worth over $10 billion.
The suspect is alleged to have stolen the jewels.

MODULE 4 – RELATIVE CLAUSES

🎯 Defining vs Non-defining

Which clauses are essential and which add optional information

🎯 Defining (Restrictive) Relative Clause

  • Identifies which one we mean — essential to the sentence
  • No commas
  • Can use that or who/which
  • Relative pronoun can be omitted when it is the object
The woman who called you is outside. (= identifies which woman)
The book that I bought yesterday is great. (= identifies which book)
The book [Ø] I bought yesterday is great. (pronoun omitted — it's the object)

💬 Non-defining (Non-restrictive) Relative Clause

  • Adds extra information — not essential; could be removed
  • Always use commas around it
  • Use which (NOT that) for things; who for people
  • The relative pronoun cannot be omitted
My brother, who lives in Paris, is a chef. (= extra info about my only brother)
The Eiffel Tower, which was built in 1889, attracts millions of tourists.

📋 Quick Comparison

DefiningNon-defining
CommasNoYes
"that"✓ allowed✗ NOT allowed
Omit pronoun✓ if object✗ never
If removedSentence loses meaningSentence still makes sense
💡 Mẹo nhớ:
Nếu câu vẫn rõ nghĩa khi bỏ mệnh đề quan hệ → non-defining (dùng dấu phẩy)
Nếu bỏ đi thì không biết đang nói về cái gì → defining (không dấu phẩy)
Test: My sister who lives in Hanoi is a teacher. (implies more than one sister → defining)
      My sister, who lives in Hanoi, is a teacher. (I have only one sister → non-defining)

MODULE 4 – RELATIVE CLAUSES

✂️ Reduced Relative Clauses

Shortening relative clauses with participles

✦ Why Reduce?

Reduced relative clauses make sentences more concise and are very common in formal writing. Remove the relative pronoun + auxiliary verb, keep the participle.

⚡ Active Reduction → Present Participle (-ing)

  • who/that + is/are + verb-ing → verb-ing
The man who is sitting by the window is my uncle.
→ The man sitting by the window is my uncle.
Students who are studying abroad face many challenges.
→ Students studying abroad face many challenges.

⚡ Passive Reduction → Past Participle (p.p.)

  • which/that + is/was + past participle → past participle
The letter which was written in 1865 is now in a museum.
→ The letter written in 1865 is now in a museum.
The bridge that was built by the French still stands today.
→ The bridge built by the French still stands today.

📌 When Can You Reduce?

  • Only in defining relative clauses
  • The pronoun must be the subject of the relative clause
  • ✗ Cannot reduce: The man whom I met… → The man I met… (pronoun is object → just omit, don't use participle)
💡 -ing vs p.p.:
-ing (present participle) = the noun is doing the action (active): the woman running in the park
p.p. (past participle) = the noun receives the action (passive): the car damaged in the accident

MODULE 4 – RELATIVE CLAUSES

📍 Relative Clauses with Prepositions

Formal vs informal preposition placement

✦ The Problem: Prepositions + Relative Pronouns

When the verb in the relative clause needs a preposition, where does it go?

📐 Two Styles

StyleStructureExample
Formalpreposition + whom/whichThe city in which I grew up is beautiful.
Informalthat/who/which + preposition at endThe city that I grew up in is beautiful.
Omit pronounØ + preposition at endThe city I grew up in is beautiful.

🔑 More Examples

FormalInformal
the hotel at which we stayedthe hotel that we stayed at
the person to whom I spokethe person who I spoke to
the reason for which she leftthe reason why she left / the reason she left
the company for which he worksthe company that he works for

📌 Special: whose + noun (possession)

The student whose essay won the prize is in my class.
The building whose roof collapsed was built in the 1960s.

Note: whose can refer to people AND things. There is no alternative like "of which" in informal use.

💡 Mẹo: Trong bài thi học thuật (IELTS, TOEFL, B1+) → dùng in which / to whom / for which để thể hiện văn phong chuyên nghiệp.
Trong giao tiếp thông thường → dùng that…in / who…to hoặc bỏ đại từ.
Không bao giờ dùng that sau giới từ: ✗ in that → ✓ in which
